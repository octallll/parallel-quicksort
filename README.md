## Запуск

Тесты:

```bash
./gradlew test
```

Бенчмарк: 10^8 элементов, 5 запусков, par на 4 потоках:

```bash
./gradlew bench
```

Другие параметры -- размер, число запусков, число потоков:

```bash
./gradlew bench --args="100000000 3 1"
```

Также дефолты можно сменить как константы в коде.
